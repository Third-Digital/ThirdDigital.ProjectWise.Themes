# Terminal-inspired dark themes

These are captures of ProjectWise Explorer with the One Half Dark, Solarized Dark and Campbell Powershell presets. Datasource, project, document, account and identifying metadata have been covered by opaque redactions; the small bars mark hidden information. No original data can be recovered from those covered pixels. The original private captures and video are not part of this repository.

- [One Half Dark](one-half-dark.png)
- [Solarized Dark](solarized-dark.png)
- [Campbell Powershell](campbell-powershell.png)

**Work in progress.** Application testing has only covered **Windows 11 Pro 26H2 (OS build 26300.9457)** and **ProjectWise Explorer CONNECT Edition 10.00.03.434 (32-bit)**. Compatibility with other versions of Windows or ProjectWise Explorer is not guaranteed.

The presets are inspired by Windows Terminal colour schemes. **A custom theme editor is planned for a future release**; it is not available in the current version.

Keep the WIP and compatibility notice with these screenshots when sharing them. The repository's private status does not change when the screenshots are shared separately.
